This repository contains code and data for Sheng Zhang's doctoral Dissertation and the Behavior Research Methods submission.
The file includes:
1) Raw dataset of the response options.
2) Item parameter files.
3) The codes for simulations.
4) The summary stats code using R Studio.


The primary data for this study are the results of an empirical simulation, which is available at the same link above. The simulation used archival raw data from a large dataset, manuscripts from which are under review (Zhang & Saxena, under review; Zhang, Saxena, Morris, under review). The data should not be used for any purposes other than review or be posted for any public use.
